## How to contribute ASCII

1. Add a new file in `/ascii/` (e.g., `sunrise.txt`).
2. Keep it under 100 lines, and under 10 KB.
3. Only include text characters (no HTML, scripts, etc.).
4. Optionally include metadata in the first 2 comment lines:

# title: Sunrise over the Bay
# artist: @yourusername
# date: 2025-10-23
